YooHoo

Private Web Project

一个以隐私为重点的 Web 开发项目。YooHoo 是一个非商业 Web 项目，用于探索私密交流场景中的网页架构、客户端加密、接口与数据存储等技术。

Web DevelopmentPrivacyClient-side EncryptionCloudflare PagesWorkersD1

项目简介

YooHoo 以私密 Web 应用为开发场景，重点研究移动端网页交互、账户访问、内容发布、回复系统以及前后端数据通信。项目为个人软件开发实践，不提供商业服务、付费功能或广告。

Web Application

研究轻量化 Web 应用的信息结构与移动端交互。

Private Community

探索私密交流场景中的访问控制与内容组织。

Software Development

持续测试前端、接口和数据层的设计方案。

技术架构

项目采用前后端分离的 Web 架构，将页面、接口与数据存储划分为相互独立的层。

FrontendHTML · CSS · JavaScript
APICloudflare Workers
StorageCloudflare D1

隐私与客户端加密

YooHoo 的开发方向包含客户端加密方案研究：敏感内容可以在浏览器端进行处理后再与服务端通信，以减少服务端直接接触明文内容的需求。具体实现会随着项目开发继续调整。

当前性质：非商业软件开发项目。此页面本身为公开项目说明页面，不要求访客登录，也不包含付费服务。

开发目标

移动端体验

优化手机浏览器中的布局、触控操作和页面加载体验。

隐私设计

研究客户端数据处理、访问控制和内容保护。

架构实践

实践 Pages、Workers 与 D1 组成的边缘 Web 架构。
